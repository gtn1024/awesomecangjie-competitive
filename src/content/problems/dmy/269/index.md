> 对于 $100\%$ 的数据，$1000 \le x \le 9999$。

## 思路

题目给定 $2026$ 年 $1$ 月 $2$ 日是该年第一场挑战赛（即 $2026$ 年 $1$ 月 $2$ 日是周五），于是 $2026$ 年 $1$ 月 $1$ 日是 **周四**。

小 A 星球每年都是平年，固定 $365$ 天，而 $365 \bmod 7 = 1$，所以每过一年，$1$ 月 $1$ 日的星期就向后顺移一天。于是 $x$ 年 $1$ 月 $1$ 日的星期相对于 $2026$ 年的偏移量为 $(x - 2026) \bmod 7$（用 `((x - 2026) % 7 + 7) % 7` 把负数也归一到 $[0, 6]$）。

记这个相对偏移为 `shift`：当 `shift = 0` 时，$x$ 年 $1$ 月 $1$ 日和 $2026$ 年一样是周四，第一场落在 $1$ 月 $2$ 日；偏移越大，第一场相对 $2026$ 年越 **靠前**（向 $1$ 月 $1$ 日靠近）。所以：

$$d = 2 - \text{shift}$$

若算出的 $d \le 0$，说明 $1$ 月 $1$ 日的星期在周四之后（周五到周六），第一个周五就在该月的更后面，需要加 $7$ 把它拉回 $1$ 月范围内。由于偏移最大为 $6$，$d$ 最小为 $2 - 6 = -4$，加 $7$ 后为 $3$，仍在 $[1, 7]$ 内，**一定落在 1 月**，月份恒为 $1$。

## 复杂度

- 时间复杂度：$O(1)$。
- 空间复杂度：$O(1)$。

## 仓颉实现

```cangjie
import std.convert.*
import std.env.*

main() {
    let reader = getStdIn()
    let x = Int64.parse(reader.readln().getOrThrow())
    let shift = ((x - 2026) % 7 + 7) % 7
    var day = 2 - shift
    if (day <= 0) {
        day += 7
    }
    println("1 ${day}")
}
```
